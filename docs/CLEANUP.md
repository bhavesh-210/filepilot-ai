# Unified cleanup workflow

Organize combines eligible scanner proposals from up to sixteen authorized initially reviewed locations
It is a bounded deterministic planning workflow rather than a new semantic model
Existing matching collections explicit Keep here decisions coding projects and protected entries remain preserved
The preview supports up to one hundred candidate files and leaves unrecognized kinds oversized files and files modified within ten seconds unselected

Choose file kind or file kind then year
Kinds include documents PDFs images audio video spreadsheets archives installers and Other
Year folders and optional filename date prefixes use modification time in UTC rather than document dates
No vendor amount subject or event is invented from a filename

Preview performs no filesystem mutations
The destination list and table show proposed folders paths and filenames
Uncheck files to exclude them from this run
Edit paths within the original authorized root
Edits can reuse existing safe directories or directories already displayed in the preview
Cross location transfers remain available separately in Main locations

Apply revalidates settings root permissions every selected source and collisions
Needed directories use the existing durable directory intent journal
Moves and renames use the exclusive transfer engine with identity and digest checks
Run membership is recorded before the filesystem move
A failure stops later actions and reports verified completion rather than claiming atomic rollback

Cleanup history persists across relaunches
Undo run restores applied files in reverse journal order and stops when a file changed or its original location is occupied
Created directories are retained and this limitation is displayed in the interface
Ambiguous journal states still require reconciliation in Activity

An optional visible checkbox saves the grouping and naming preset for future arrivals
Saving a preset authorizes that displayed preset for all its selected roots rather than only the currently selected preview rows
One off path edits do not become automatic rules
Full and Limited modes can run this explicitly approved preset
Smart Approval never runs it automatically
Disable automatic layout removes the saved profile
Saved profiles take precedence over older automatic category rules for those roots
A live cleanup preview holds its selected locations against background changes
Clear mode or permission changes invalidate stale previews

The refreshed interface uses a light system palette compact controls conventional tables and direct status text
Semantic entity extraction OCR richer summaries prompt interpretation and full content based naming remain future milestones
This build does not claim those features or a guaranteed two file review queue
