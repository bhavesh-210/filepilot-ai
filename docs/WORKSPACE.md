# Main locations and quieter review

Main locations brings all active approved roots into one workspace
Desktop Downloads Documents Pictures Music and Movies have separate location cards
Other approved roots keep their own cards too
Each card reports inventoried files folders waiting items protected entries sent received and applied operations
Incomplete scans are labelled rather than presented as a complete census

## Review and routing

Two items are in focus by default and View all waiting shows the true remaining queue
This is an attention limit and not a claim that only two files are uncertain
The Recommended label identifies the best available suggestion and does not prove its accuracy

Preview the proposed category layout before approving its rules
Rules can reuse existing folders or explicitly create one named destination folder
A saved category rule applies across all approved and initially reviewed source locations
Full and Limited modes can apply these explicitly approved rules in the background
Smart Approval keeps execution behind approval
Clearing rules or changing mode invalidates older permissions

Optional content rules use complete short text or complete bounded PDF text
They require at least three matching category keywords and no competing category evidence
This is a deterministic user approved keyword rule rather than calibrated ML confidence
Text is limited to 8000 bytes and fewer than 2000 characters
PDF input is limited to 2 MiB five pages and 2000 extracted characters with no OCR
Partial unsupported ambiguous and larger documents remain for review
At most 64 short text inspections and two new PDF inspections are attempted per cycle
Only metadata is cached for PDF routing and no document contents are persisted there

## Transfers and Undo

Both source and destination need current authorization and completed first previews
File transfers require stable ordinary files on the same filesystem volume
The source is checked again against its preview and contents are hashed around exclusive no overwrite renames
Each operation records both location identities and supports guarded Undo
Undo records a Keep here decision so automatic maintenance does not immediately redo it
Ambiguous interrupted operations require reconciliation rather than guessing

Whole ordinary folders can be moved through an explicit separate preview and confirmation
The folder hierarchy and filenames are retained and destination folders are never merged
A folder preview temporarily holds its subtree against automatic organisation
Limits are 100 files 256 MiB 512 entries and 16 nested levels
Each file must be stable for ten seconds and no larger than 64 MiB
Projects protected paths symlinks hardlinks special entries and cloud placeholders reject the whole folder move
Folder transfers are never automatic
Undo requires the entire tree to remain unchanged

## Permissions and coverage

Select sibling test locations together through the macOS picker
An active narrow test grant must be revoked before granting its overlapping parent
Historical operation records are retained and access is not silently broadened
Renew access for locations marked Access needed before expecting maintenance there
Recents is a Finder view rather than a separate filesystem root
Applications system paths projects and unavailable cloud content remain protected
The app does not take unrestricted control of Finder
Cross volume transfers production signing and real Mac permission acceptance remain open
