## User outcome

Choose permitted locations once and describe the desired result or select a preset
Analyse the existing hierarchy and supported contents locally
Propose a coherent editable destination tree and naming scheme
Approve the first cleanup as one understandable plan
Maintain future arrivals under that approved policy
Ask only for unresolved consequential decisions and retain a complete activity trail

The two item focus is only presentation and must not be used as evidence of improved classification
Review workload reduction must come from correct decisions reusable preferences and grouped decisions
Uncertain untouched files must remain discoverable

## What to retain

Keep authorized root boundaries project protection no overwrite operations persistent journaling cancellation and guarded Undo
Retain multiple locations per directory stats and separate Trash confirmation
The AI proposes structured data and never executes paths or instructions from file contents
No network model calls telemetry or personal document uploads

## Next milestone whole cleanup planning

- [ ] Define a versioned organization profile with source roots allowed destination roots folder structure and naming policies
- [ ] Support presets for file kind and kind then year before unconstrained AI plans
- [ ] Inventory the combined authorized workspace and preserve existing meaningful collections
- [ ] Produce one read only plan containing directories moves renames unchanged files and unresolved decisions
- [ ] Present a destination tree with counts and original to proposed filename rows
- [ ] Permit destination edits exclusions and grouped decisions before approval
- [ ] Compile approved profiles into reusable background policy
- [ ] Group journal records by cleanup run and implement guarded Undo run with honest partial outcomes
- [ ] Test preview immutability collisions policy changes interrupted runs project boundaries and stale sources

Do not present new UI controls as working until the engine and integration checks support them
Existing first cleanup and collection tokens remain separate until this milestone safely unifies their behavior

## Following milestone local intelligence

- [ ] Define bounded structured extraction for document type dates organizations and relevant entities
- [ ] Add OCR for scans and supported images through a bounded native worker
- [ ] Add individually audited document parsers rather than pretending all formats are understood
- [ ] Rank destinations against existing folders using a locally evaluated embedding model
- [ ] Evaluate an optional local model for preference interpretation and summaries with strict output schema validation
- [ ] Verify extracted evidence before using it in names and avoid fabricated dates vendors or amounts
- [ ] Evaluate accuracy review coverage correction effort and project preservation on independent licensed fixtures

A supported preferences editor remains available without downloading an optional model
Document snippets and model output never grant permissions

## Experience after the engine milestone

Onboarding selects permissions and a simple profile
Organize shows before and after structure and one initial apply action
Automation shows persistent per location policies pause status and failures
Needs attention groups decisions with recommendations and evidence
Activity shows cleanup runs and individual reversible operations
Advanced rules remain optional rather than the main user workflow
Quick Look drag and drop menu bar controls and Shortcuts can follow the main cleanup workflow

## Acceptance example

An allowed Downloads folder contains vague nested documents
A user selects grouping by topic then year and approves Documents as a destination
The read only planner proposes meaningful folders and proposed names with evidence
No unsupported or ambiguous evidence is silently invented
A single approval applies eligible steps and records the run
New arrivals follow the approved profile
User corrections adjust local preferences explicitly
Undo restores eligible names and locations without overwriting unrelated files
